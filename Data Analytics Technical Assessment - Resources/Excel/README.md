# Excel Assessments

This folder contains the datasets, formulas, and answer keys used during the live technical assessments.

## 🎯 Purpose

These files demonstrate the ability to clean, analyze, and visualize data using Microsoft Excel without relying on external notes.

## 🛠️ Skills Demonstrated

- **Lookups:** `XLOOKUP`, `INDEX` + `MATCH`, `VLOOKUP`
- **Math & Stats:** `SUMIFS`, `COUNTIFS`, `AVERAGEIFS`
- **Logic:** `IF`, `Nested IF`, `IFS`
- **Text & Dates:** `LEFT`, `RIGHT`, `MID`, `CONCAT`, `TEXT`
- **Data Analysis:** Pivot Tables, Pivot Charts, Slicers, Calculated Fields
- **Formatting & Validation:** Conditional Formatting, Data Validation (Dropdowns)
