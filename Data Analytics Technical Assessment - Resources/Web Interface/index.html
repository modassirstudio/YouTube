02 / DATABASES

SQL practice

Queries covering filtering, aggregation, joins and advanced SQL.

02

Part 1 Basics

1. Products priced above 100

SELECT name AS Products
FROM products
WHERE price > 100;

Correct approach

2. First five customers alphabetically

SELECT name
FROM customers
ORDER BY name ASC
LIMIT 5;

Check this: use ASC for A–Z and LIMIT 5 to return only five rows.

3. Sales during September 2026

SELECT *
FROM sales
WHERE sale_date >= '2026-09-01'
  AND sale_date <  '2026-10-01';

Recommended date-range pattern

This includes all times on September 30 when sale_date is a datetime column.

4. Count all sales

SELECT COUNT(*) AS Number_of_Sales
FROM sales;

Correct

Part 2 Aggregation

5. Total sales amount by category, highest first

SELECT p.category AS Category,
       SUM(s.amount) AS Total_Sales_Amount
FROM products p
INNER JOIN sales s
    ON p.product_id = s.product_id
GROUP BY p.category
ORDER BY Total_Sales_Amount DESC;

Correct approach

6. Average quantity sold per product

SELECT p.name AS Product,
       AVG(s.quantity) AS Average_Quantity_Per_Product
FROM products p
INNER JOIN sales s
    ON p.product_id = s.product_id
GROUP BY p.product_id, p.name;

Correct approach

7. Count sales per customer

SELECT c.name AS Customer,
       COUNT(*) AS Count_of_Sales
FROM customers c
INNER JOIN sales s
    ON c.customer_id = s.customer_id
GROUP BY c.customer_id, c.name;

Correct for customers who have at least one sale

8. Highest sale amount for each calendar date

SELECT sale_date,
       MAX(amount) AS Highest_Amount
FROM sales
GROUP BY sale_date
ORDER BY sale_date;

Check this: DAYNAME(sale_date) groups every Monday together. Group by sale_date to get the maximum for each date.

Part 3 Joins

9. Sales with customer and product names

SELECT c.name AS Customer,
       p.name AS Product,
       s.*
FROM sales s
INNER JOIN products p
    ON s.product_id = p.product_id
INNER JOIN customers c
    ON s.customer_id = c.customer_id;

Correct approach

10. Every customer and their total spending, including zero

SELECT c.name AS Customer,
       COALESCE(SUM(s.amount), 0) AS Total_Spending
FROM customers c
LEFT JOIN sales s
    ON c.customer_id = s.customer_id
GROUP BY c.customer_id, c.name;

Your LEFT JOIN idea was right. COALESCE changes NULL to 0 for customers with no sales.

11. Every product and its total revenue, including zero sales

SELECT p.name AS Product,
       COALESCE(SUM(s.amount), 0) AS Revenue
FROM products p
LEFT JOIN sales s
    ON p.product_id = s.product_id
GROUP BY p.product_id, p.name;

Use COALESCE so products with no sales display 0 rather than NULL.

12. Products that have never been sold

SELECT p.name AS Product
FROM products p
LEFT JOIN sales s
    ON p.product_id = s.product_id
WHERE s.sale_id IS NULL;

Correct if sale_id is a non-null key in sales

Part 4 Advanced SQL

13. Categories with an average sale amount above 200

SELECT p.category AS Category,
       AVG(s.amount) AS Average_Amount
FROM products p
INNER JOIN sales s
    ON p.product_id = s.product_id
GROUP BY p.category
HAVING AVG(s.amount) > 200;

Check this: category belongs to products, so join products to sales and group by category. HAVING filters aggregated groups.

14. Rank products by total revenue

SELECT p.name AS Product,
       SUM(s.amount) AS Revenue,
       RANK() OVER (ORDER BY SUM(s.amount) DESC) AS Revenue_Rank
FROM products p
INNER JOIN sales s
    ON p.product_id = s.product_id
GROUP BY p.product_id, p.name;

Correct window-function idea

15. Running total ordered by sale date

SELECT sale_id,
       sale_date,
       amount,
       SUM(amount) OVER (
           ORDER BY sale_date, sale_id
           ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
       ) AS Running_Total
FROM sales
ORDER BY sale_date, sale_id;

Check this: do not GROUP BY sale_id or use SUM(amount) as the row's amount. A running total adds each sale row to the previous rows.

=INDEX(E2:E11, MATCH("Marker", B2:B11, 0))

2. Find the product priced at ₹35; otherwise return “Out of stock”

=XLOOKUP(35, E2:E11, B2:B11, "Out of stock")

Correct if prices are in E and product names are in B.

3. Find the category of “Chips”

=INDEX(C2:C11, MATCH("Chips", B2:B11, 0))

Correct if categories are in C.

4. Find the customer for Order_ID 1005

=INDEX(F2:F11, MATCH(1005, A2:A11, 0))

Correct if order IDs are in A and customer names are in F.

Part 4 Spreadsheet concepts

13. Create a PivotTable for total sales per category

  1. Select the data range, including column headers.
  2. Choose Insert → PivotTable.
  3. Confirm the range and choose where the PivotTable should appear.
  4. Drag Category into Rows.
  5. Drag Sales Amount (or the relevant amount/price field) into Values.
  6. Open Value Field Settings and select Sum if Excel does not choose it automatically.

Your steps were mostly right. Use the actual sales amount field for “Total Sales,” rather than price if the task refers to transaction totals.

14. Highlight quantities greater than 10 in green

  1. Select the quantity cells.
  2. Go to Home → Conditional Formatting → Highlight Cells Rules → Greater Than (or choose New Rule).
  3. Enter 10.
  4. Choose a green fill format.
  5. Click OK.

Your approach was correct; choose the green formatting and confirm with OK.

15. Create a Yes/No dropdown using Data Validation

  1. Select the cell or range where the dropdown is needed.
  2. Go to Data → Data Validation.
  3. Under Allow, choose List.
  4. In Source, type Yes,No.
  5. Make sure the in-cell dropdown option is enabled, then click OK.

Revision task: practise this once in Excel so you remember the menu path.
