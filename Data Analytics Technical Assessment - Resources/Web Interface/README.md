# Assessment Web Interface

This folder contains the HTML and CSS files for the web interface of the technical assessments. 

## 🎯 Purpose

Instead of just reading raw code in a text file, this interface provides a clean, browser-based layout to view the exam questions, code snippets, and datasets exactly as they appeared during the YouTube live coding sessions.

## 🛠️ Built With

- **HTML5** — Structure and content.
- **CSS3** — Styling and layout.

## 🚀 How to Use

1. Clone or download this repository.
2. Open the `index.html` file in any web browser (Chrome, Edge, Safari, etc.).
3. Navigate through the interface to view the assessment materials.
