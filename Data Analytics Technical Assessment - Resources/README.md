# Assessment Resources

This folder contains the core study materials, syllabus, and topic lists that are tested during the live technical assessments.

## 🎯 Purpose

The purpose of this folder is to provide a transparent look at the exact curriculum and topics covered. These are the foundational skills required for an entry-level Data Analyst role, covering SQL, Excel, Python, and general data logic.

## 🛠️ Topics Covered

- **SQL Fundamentals:** `SELECT`, `WHERE`, `GROUP BY`, `HAVING`, `JOINs`, Subqueries, and Window Functions.
- **Excel for Data Analysis:** Lookup functions (`XLOOKUP`, `INDEX/MATCH`), Aggregation (`SUMIFS`, `COUNTIFS`), Logic (`IF/IFS`), Pivot Tables, and Data Validation.
- **Python Basics:** Variables, Loops, Functions, and basic `pandas` DataFrame manipulation.
- **Data Logic & Problem Solving:** Translating business questions into data queries.
