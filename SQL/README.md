# SQL Assessments

This folder contains the raw SQL scripts written during the live technical assessments. 

## 🎯 Purpose

These files contain the exact queries written on camera without any notes or Googling. They demonstrate how to solve real-world business problems using MySQL.

## 🛠️ Skills Demonstrated

- **Basic Queries:** `SELECT`, `WHERE`, `ORDER BY`, `LIMIT`
- **Aggregations:** `GROUP BY`, `HAVING`, `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`
- **Joins:** `INNER JOIN`, `LEFT JOIN`, multi-table joins
- **Advanced Functions:** `CASE` statements, Subqueries, CTEs (`WITH`), Window Functions (`RANK`, `ROW_NUMBER`, `SUM() OVER()`)
- **String & Date Functions:** `CONCAT`, `UPPER`, `SUBSTRING`, `DATEDIFF`, `YEAR`, `MONTH`
