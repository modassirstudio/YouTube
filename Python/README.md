# Python Assessments

This folder contains the raw `.py` scripts written during the live coding assessments.

## 🎯 Purpose

These files demonstrate foundational Python programming and basic data manipulation skills required for entry-level Data Analyst roles.

## 🛠️ Skills Demonstrated

- **Basics:** Variables, Data Types, Math Operators
- **Data Structures:** Lists, Dictionaries, Tuples
- **Control Flow:** `for` loops, `while` loops, `if/else` statements
- **Functions:** Defining functions, arguments, return statements
- **Data Manipulation:** Basic `pandas` DataFrames (loading, filtering, groupby)
